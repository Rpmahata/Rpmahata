## 🧠 About Me

I'm a **Senior SDET** with 6+ years in QA — spanning test automation, performance engineering, ETL testing, and manual testing at a WMS (Warehouse Management Systems) company. Alongside my QA work, I architect and build **AI-native automation platforms** that push the boundaries of what testing tooling can do.

My focus area is the intersection of **Large Language Models + agentic systems + software quality** — designing multi-agent pipelines where AI does the heavy lifting: generating test cases, exploring applications, assembling requirements knowledge, and writing automation code.

- 🔨 Currently building **QARC** — an AI platform that bridges Business Analysis and QA into one intelligent workflow
- 🤖 Previously built **TESS** — a multi-agent swarm platform for test execution and self-healing automation
- 📐 I design systems architecture-first: RAG pipelines, MCP servers, agentic loops, Spec Graphs
- 🌱 Exploring AI evaluation platforms (Mercor, Turing) and fractional QA consulting
- ⚡ I use Claude Code with custom multi-agent pipelines to build faster — my `/build` command runs a full plan → code → review → test loop autonomously

## 🚀 Featured Projects

### 🧪 QARC — QA & Requirements Co-Pilot
> An AI platform that unifies Business Analysis and QA into a single agentic workflow

- **7 specialized agents**: App Explorer, Requirements Analyst, Test Strategist, Test Case Generator, Automation Engineer, Quality Oracle, Chat Agent
- **Specification Graph** (PostgreSQL + pgvector) as single source of truth shared across all agents
- **Knowledge Assembly Pipeline**: deep Jira/Confluence import with AC parsing, comment decision extraction, vision analysis on attachments
- **3-layer no-code automation editor**: visual drag-and-drop + NL assist + code view, compiled to Playwright via StepGraph JSON
- **12 MCP tool servers**, Claude API tool_use agentic loop, FastAPI + React/Vite + Celery + Redis
- Implemented Phase 3: 42 Python source files, 5 working agents, 4 MCP servers, 8 FastAPI routers

### 🤖 TESS — Test Execution and Self-healing System
> Enterprise multi-agent swarm architecture for AI-powered test automation

- Hybrid retrieval pipeline: **ChromaDB + BM25 + BGE reranker** with RRF fusion
- Multi-phase RAG pipeline for test case generation with 4-step quality pipeline (LLM dedup → ChromaDB → Coverage → Gap fill)
- Manual TC lifecycle state machine with version history
- Stack: Python/FastAPI, SQLAlchemy, ChromaDB, Gemini, Ollama, Playwright, Selenium, React/Vite, Electron

---

### 🔧 CodePilot — Autonomous Multi-Agent Engineering Pipeline
> A custom Claude Code configuration that drives the full software development lifecycle autonomously

- 9-file configuration system: `CLAUDE.md`, subagents, hooks, orchestrator skill
- `/build` command triggers a full **plan → code → review → test** loop without manual phase-by-phase approval
- Built on Claude Code's agent infrastructure with custom hooks and orchestration

---

### 📦 EDI Flat File Comparison Tooling
> Python-based comparison and diff tooling for logistics EDI formats

- Three production scripts: `edi_compare.py`, `wm_compare.py`, `asn_compare.py`
- Supports **GEX, Walmart 315, ASN 856** formats with auto-detection
- Outputs Excel + HTML diff reports
- Generic engine with pluggable configuration manager for schema formats
